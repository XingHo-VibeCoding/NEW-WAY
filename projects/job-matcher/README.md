# 求职岗位智能匹配 Skill

## 简介

这是一个帮助求职者高效匹配岗位的技能。它能在Boss直聘、脉脉等求职平台上自动搜索岗位，筛选活跃岗位，基于用户简历进行匹配度分析，并生成推荐开场白。

## 解决的痛点

1. **手动查看效率低**：求职者需要逐个点击岗位查看详情，对比自己简历的匹配程度，非常耗时
2. **无效岗位多**：求职平台推荐的岗位很多很久没活跃，投递后没有回复
3. **匹配度不明确**：不清楚自己与岗位的匹配程度，不知道该重点投递哪些

## 核心功能

- ✅ **多平台支持**：支持Boss直聘、脉脉等多个求职平台
- ✅ **自动搜索岗位**：根据求职目标自动搜索相关岗位
- ✅ **筛选活跃岗位**：只保留最近一个月活跃的岗位，避免无效投递
- ✅ **匹配度评分**：基于简历自动评估岗位匹配度（0-100分）
- ✅ **优缺点分析**：分析用户与岗位的匹配点和差距
- ✅ **推荐开场白**：为每个岗位生成个性化的沟通开场白
- ✅ **内推机会挖掘**：脉脉平台可直接联系目标公司员工获取内推
- ✅ **完整报告**：输出结构化的岗位匹配分析报告

## 使用方法

### 前置条件

1. 确保简历信息已记录在 `USER.md` 或相关记忆文件中
2. Boss直聘账号已准备好（需要登录）
3. 脉脉账号已准备好（需要登录）

### 快速开始

**方式1：双平台搜索**

```
帮我找杭州的技术支持岗位，要求是AI/Agent方向的
```

**方式2：指定平台搜索**

```
帮我在Boss直聘上找上海的大模型应用开发岗位，薪资要求30K以上
```

**方式3：脉脉内推搜索**

```
帮我在脉脉上找阿里的岗位，最好能找到内推机会
```

### 执行流程

1. 收集简历信息（从记忆文件或用户输入）
2. 确定平台：Boss直聘、脉脉或两者
3. 登录平台并搜索岗位
4. 筛选最近一个月活跃的岗位
5. 获取岗位详情（JD、薪资、链接、招聘者信息）
6. 分析匹配度、生成优缺点分析和开场白
7. 输出完整报告

## 输出示例

### 岗位匹配分析报告

**文件名**：`岗位匹配分析报告.md`

**报告结构**：
- 一、用户简历概览
- 二、岗位匹配分析（按匹配度排序）

## 匹配度评分标准

### 评分维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 技术栈匹配 | 30% | JD要求的技术栈与用户技能的重合度 |
| 经验匹配 | 25% | 工作年限、项目经验是否满足要求 |
| 行业背景 | 15% | 用户过往行业经验是否匹配 |
| 学历匹配 | 10% | 学历要求是否满足 |
| 薪资匹配 | 10% | 薪资范围是否与用户期望匹配 |
| 证书加分 | 10% | 专业认证是否匹配 |

### 匹配度等级

- **85-100分**：高度匹配，强烈推荐投递
- **70-84分**：中度匹配，重点关注
- **55-69分**：一般匹配，可以考虑
- **55分以下**：匹配度较低，不推荐

## 注意事项

1. **登录状态**：Boss直聘和脉脉都需要登录才能查看完整信息
2. **活跃时间**：活跃时间是动态信息，点击链接可查看实时状态
3. **匹配度参考**：评分仅供参考，具体面试结果取决于实际表现
4. **时效性**：岗位信息会变化，建议定期更新搜索结果
5. **脉脉特有**：脉脉平台可以联系目标公司员工获取内推机会
