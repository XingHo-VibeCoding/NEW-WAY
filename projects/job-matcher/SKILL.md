# 求职岗位智能匹配 Skill

## 任务本质

帮助求职者在Boss直聘、脉脉等求职平台上高效找到匹配岗位，自动筛选活跃岗位，生成匹配度分析和沟通建议。

**核心价值**：
- **多平台支持**：支持Boss直聘、脉脉等多个求职平台
- **自动筛选活跃岗位**：过滤掉很久没活跃的无效岗位，节省求职者时间
- **智能匹配度分析**：基于简历自动评估岗位匹配度，生成优缺点分析
- **一键生成开场白**：为每个岗位生成个性化推荐开场白，提高沟通效率
- **内推机会挖掘**：脉脉平台可直接联系目标公司员工获取内推

**能力限制**：
- 目前支持Boss直聘、脉脉平台
- 需要用户提供完整的简历信息
- 匹配度评分基于简历和JD的文本匹配，仅供参考

---

## 执行流程

### 流程概述

```
Step 1: 收集简历信息 → 获取用户的简历和求职目标
Step 2: 平台选择 → 确定使用Boss直聘、脉脉或两者
Step 3: 平台登录检查 → 确认平台登录状态
Step 4: 搜索岗位 → 根据求职目标搜索相关岗位
Step 5: 筛选活跃岗位 → 过滤最近一个月活跃的岗位
Step 6: 获取岗位详情 → 抓取JD、薪资、链接、招聘者信息
Step 7: 匹配度分析 → 基于简历评估匹配度、生成优缺点分析
Step 8: 生成报告 → 输出完整的岗位匹配分析报告
```

---

### Step 1: 收集简历信息

**核心任务**：收集用户的简历信息和求职目标。

#### 1.1 检查已有信息

检查以下来源是否已有用户简历信息：
1. 用户上传的简历文件（PDF/Word）
2. 记忆文件中的简历信息（`USER.md`、`MEMORY.md`）
3. 用户当前对话中提供的简历信息

#### 1.2 信息收集清单

必须收集的核心信息：
- **基本信息**：姓名、联系方式、学历
- **工作经历**：公司名称、职位、时间、主要职责
- **项目经验**：项目名称、技术栈、成果
- **核心技能**：技术栈、专业认证、特殊能力
- **求职目标**：目标岗位、期望薪资、工作地点

**操作原则**：
- 如果信息不完整，主动询问用户补充
- 可以使用 memory_search 工具搜索历史记忆
- 如果用户上传了简历文件，使用 parse_file 工具解析

#### 1.3 构建简历摘要

将收集到的信息整理成结构化的简历摘要，供后续匹配分析使用。

---

### Step 2: 平台选择

**核心任务**：确定使用哪个求职平台进行搜索。

#### 2.1 支持的平台

| 平台 | 特点 | 适用场景 |
|------|------|---------|
| **Boss直聘** | 岗位数量多，直接沟通Boss | 求职首选平台，岗位覆盖全面 |
| **脉脉** | 内推机会多，职场社交 | 大厂内推，了解公司真实情况 |

#### 2.2 平台选择策略

**默认策略**：
- 用户未指定时，同时搜索Boss直聘和脉脉
- 用户指定平台时，只搜索指定平台

**主动询问**：
- 如果用户没有明确平台偏好，询问是否需要同时搜索多个平台

**示例对话**：
```
用户：帮我找杭州的技术支持岗位
Agent：好的，我会同时搜索Boss直聘和脉脉两个平台。如果你只想搜索某个平台，可以告诉我。
```

### Step 3: 平台登录检查

**核心任务**：确认平台登录状态，确保可以正常搜索岗位。

#### 3.1 Boss直聘登录检查

使用 `agent-browser` 技能打开Boss直聘网站。

**操作命令**：
```bash
agent-browser open "https://www.zhipin.com"
```

**未登录处理**：
1. 提示用户完成登录（手机号验证码/扫码）
2. 等待用户确认登录完成
3. 再次检查登录状态

#### 3.2 脉脉登录检查

使用 `agent-browser` 技能打开脉脉网站。

**操作命令**：
```bash
agent-browser open "https://maimai.cn"
```

**未登录处理**：
1. 提示用户完成登录（手机号验证码/扫码）
2. 等待用户确认登录完成
3. 再次检查登录状态

---

### Step 4: 搜索岗位

**核心任务**：根据用户的求职目标，在各个平台上搜索相关岗位。

#### 4.1 Boss直聘搜索

**确定搜索关键词**：

根据用户的求职目标确定搜索关键词：
- **岗位关键词**：目标岗位名称（如"技术支持"、"AI工程师"）
- **技术关键词**：核心技能（如"Agent"、"LLM"、"RAG"）
- **组合搜索**：岗位 + 技术（如"技术支持 Agent"、"AI工程师 大模型"）

**关键词策略**：
1. 先使用核心关键词搜索
2. 如果结果太少，扩展到相关关键词
3. 如果结果太多，增加技术限定词

**构建搜索URL**：

Boss直聘搜索URL格式：
```
https://www.zhipin.com/web/geek/job?query={关键词}&city={城市代码}
```

常见城市代码：
- 杭州：101210100
- 北京：101010100
- 上海：101020100
- 深圳：101280100
- 广州：101280100

**操作示例**：
```bash
agent-browser open "https://www.zhipin.com/web/geek/job?query=技术支持+Agent&city=101210100"
```

**获取搜索结果**：

等待页面加载完成后，获取页面快照或截图，识别岗位列表。

**关键信息提取**：
- 岗位名称
- 公司名称
- 薪资范围
- 工作地点
- Boss活跃状态（今日活跃、3日内活跃等）

#### 4.2 脉脉搜索

**确定搜索关键词**：

根据用户的求职目标确定搜索关键词，与Boss直聘类似。

**搜索方式**：

脉脉的搜索方式与Boss直聘略有不同：
1. **职位搜索**：在脉脉首页或职场版块搜索岗位
2. **公司主页搜索**：直接访问目标公司的品牌主页
3. **职场话题搜索**：在职场话题中寻找相关岗位

**操作示例**：
```bash
# 方式1：职位搜索
agent-browser open "https://maimai.cn/search?type=job&query=技术支持+Agent"

# 方式2：公司主页（如阿里）
agent-browser open "https://maimai.cn/brand/home/xxx"
```

**获取搜索结果**：

等待页面加载完成后，获取页面快照或截图，识别岗位列表。

**关键信息提取**：
- 岗位名称
- 公司名称
- 薪资范围
- 工作地点
- 发布时间/活跃时间
- 岗位链接

---

### Step 5: 筛选活跃岗位

**核心任务**：过滤掉很久没活跃的无效岗位，只保留最近一个月活跃的岗位。

#### 5.1 Boss直聘活跃时间判断

Boss直聘上常见的活跃时间标识：
- **刚刚活跃** → ✅ 保留
- **今日活跃** → ✅ 保留
- **3日内活跃** → ✅ 保留
- **本周活跃** → ✅ 保留
- **2周内活跃** → ✅ 保留
- **本月活跃** → ✅ 保留
- **超过1个月** → ❌ 过滤

#### 5.2 脉脉活跃时间判断

脉脉上常见的活跃时间标识：
- **最近发布** → ✅ 保留
- **1周内发布** → ✅ 保留
- **2周内发布** → ✅ 保留
- **1个月内发布** → ✅ 保留
- **超过1个月** → ❌ 过滤

**注意**：脉脉的岗位发布时间可能显示为"X天前"，需要根据当前日期计算是否在一个月内。

#### 5.3 筛选规则

**强制规则**：只保留最近一个月内活跃的岗位。

**优先级排序**（活跃度从高到低）：
1. 刚刚活跃 / 今日活跃
2. 3日内活跃
3. 本周活跃
4. 2周内活跃
5. 本月活跃

**操作方式**：
- 从搜索结果中识别活跃时间
- 过滤掉超过1个月未活跃的岗位
- 对保留的岗位按活跃度排序

---

### Step 6: 获取岗位详情

**核心任务**：为每个筛选后的岗位获取详细信息，包括JD、岗位链接、招聘者信息等。

#### 6.1 岗位数量控制

建议获取 **10-15个岗位** 的详细信息：
- 数量太少：样本不足，可能错过好机会
- 数量太多：分析时间过长，信息过载

#### 6.2 Boss直聘信息提取

对于每个岗位，需要提取：

**基本信息**：
- 岗位名称
- 公司名称
- 薪资范围
- 工作地点
- 学历要求
- 工作经验要求

**详细信息**：
- 岗位JD（职位描述、任职要求）
- 岗位链接（完整的Boss直聘URL）
- Boss姓名和职位
- Boss活跃时间
- 公司规模/行业（可选）

#### 6.3 脉脉信息提取

对于每个岗位，需要提取：

**基本信息**：
- 岗位名称
- 公司名称
- 薪资范围
- 工作地点
- 学历要求
- 工作经验要求

**详细信息**：
- 岗位JD（职位描述、任职要求）
- 岗位链接（完整的脉脉URL）
- 招聘者姓名和职位
- 发布时间/活跃时间
- 公司规模/行业（可选）
- 内推机会（是否可以联系公司员工获取内推）

**操作方式**：
- 点击岗位进入详情页
- 获取页面快照或截图
- 提取上述信息
- 记录岗位链接（浏览器地址栏URL）

### Step 7: 匹配度分析

**核心任务**：基于用户简历，评估每个岗位的匹配度，生成优缺点分析和推荐开场白。

#### 7.1 匹配度评分标准

**评分维度**（总分100分）：

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 技术栈匹配 | 30% | JD要求的技术栈与用户技能的重合度 |
| 经验匹配 | 25% | 工作年限、项目经验是否满足要求 |
| 行业背景 | 15% | 用户过往行业经验是否匹配 |
| 学历匹配 | 10% | 学历要求是否满足 |
| 薪资匹配 | 10% | 薪资范围是否与用户期望匹配 |
| 证书加分 | 10% | 专业认证（如ACP、PMP）是否匹配 |

**匹配度等级**：
- **85-100分**：高度匹配，强烈推荐投递
- **70-84分**：中度匹配，重点关注
- **55-69分**：一般匹配，可以考虑
- **55分以下**：匹配度较低，不推荐

#### 7.2 匹配分析内容

对每个岗位生成：

**优势点（3-5条）**：
- 用户具备的技能与JD要求的匹配点
- 用户的项目经验与岗位需求的契合点
- 用户的行业背景与公司业务的关联点
- 专业认证的加分项

**需提升的点（2-3条）**：
- 用户欠缺的技能或经验
- 与JD要求有差距的地方
- 建议补充的知识或能力

#### 7.3 推荐开场白生成

**开场白结构**：
1. **开场问候**：您好！
2. **应聘意向**：看到[岗位名称]岗位，非常感兴趣
3. **核心亮点**：突出最匹配的1-2个亮点（项目经验、技能、证书）
4. **价值主张**：我能为公司带来什么价值
5. **行动号召**：期待有机会深入交流

**开场白示例**：
> 您好！看到贵司AI Agent技术架构师岗位。我最近主导了企业内部AI Coding助手项目，采用Agent + MCP + RAG架构，成功将交付周期从2周压缩至1小时。同时持有阿里云大模型ACP认证，5年技术服务经验中积累了丰富的大模型落地经验。希望有机会深入交流！

**开场白原则**：
- 控制在100字以内
- 突出与岗位最匹配的亮点
- 量化成果（如"提升30%"、"压缩至1小时"）
- 避免空泛的套话

---

### Step 8: 生成报告

**核心任务**：输出完整的岗位匹配分析报告，便于用户查阅和决策。

#### 8.1 报告结构

报告应包含以下章节：

**一、用户简历概览**
- 基本信息
- 核心能力
- 工作经历
- 代表项目
- 专业认证

**二、Boss直聘岗位匹配分析**（如搜索了Boss直聘）
- 按匹配度从高到低排序
- 每个岗位包含：
  - 基本信息表（薪资、公司、地点、学历、匹配度、岗位链接、Boss活跃时间）
  - 匹配分析（优势点 + 需提升的点）
  - 推荐开场白

**三、脉脉岗位匹配分析**（如搜索了脉脉）
- 按匹配度从高到低排序
- 每个岗位包含：
  - 基本信息表（薪资、公司、地点、学历、匹配度、岗位链接、发布时间）
  - 匹配分析（优势点 + 需提升的点）
  - 推荐开场白
  - 内推机会提示

**四、投递策略建议**
- 优先级排序（第一梯队、第二梯队、第三梯队）
- 简历优化建议
- 面试准备重点
- 脉脉特有技巧（内推、职场问答等）

**五、总结**
- 核心优势总结
- 行动建议

#### 8.2 报告格式

使用Markdown格式输出，包含：
- 清晰的标题层级
- 表格展示关键信息
- 列表展示分析要点
- 引用块展示推荐开场白

#### 8.3 文件保存

将报告保存为Markdown文件：
- 文件名：`岗位匹配分析报告.md`
- 位置：当前工作目录

## 注意事项

1. **登录状态**：Boss直聘和脉脉都需要登录才能查看完整信息，确保用户完成登录
2. **活跃时间**：活跃时间是动态信息，点击岗位链接后可在页面查看实时状态
3. **匹配度参考**：匹配度评分仅供参考，具体面试结果还取决于实际表现
4. **隐私保护**：不要在报告中泄露用户敏感信息（如身份证号、详细住址）
5. **时效性**：岗位信息会变化，建议定期更新搜索结果
6. **脉脉特有**：脉脉平台可以联系目标公司员工获取内推机会，充分利用这一优势

---

## 执行约束

1. **必须先登录**：Boss直聘和脉脉都需要登录才能查看岗位详情，未登录时必须提示用户
2. **必须筛选活跃岗位**：只保留最近一个月活跃的岗位，避免无效投递
3. **必须提供岗位链接**：每个岗位都要附上完整的平台链接
4. **必须生成开场白**：为每个岗位生成个性化的推荐开场白
5. **必须保存报告**：将完整报告保存为Markdown文件
6. **脉脉内推提示**：如果搜索了脉脉，报告中必须包含内推机会提示
