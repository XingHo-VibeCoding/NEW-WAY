## 四、本周最花时间的一步 + 值不值（今日思考题）

**最花时间的一步：Day 17–18 打通云端读写与跨域（含 401/503 两轮排查）。**

**为什么最花时间**：不是代码难，是**云端事实本地测不出来** —— 令牌档位（读用 Publishable Key、写必须 API Key）、
网关触发路径、CORS 到底谁在管，这些「打进去才知道」，本地假网关永远模拟不出来。

**值不值：值。** 理由三条：
1. 这三个坑**每个都会在后面每个接口重演**（entries、matches 都要走同一条路），现在摸清了，后面是抄。
2. 换来的是一条**真实可用的端到端链路**：别人打开一个网址，能真的往里记一笔、刷新还在。
3. 「本地绿 ≠ 云端绿」这条认知，比任何单个接口都重要 —— 这就是 Day 16 那句「目视检查 ≠ 真实运行」的云端版。
