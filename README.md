项目名：Ledger and Career-简册
简介：
一本职场人的双面账簿。
第一面记钱：收支、账单、存款，看清每个月钱去哪了。
第二面记经历：工作、项目、成长，随时导出一份简历。
你可以只用其中一面，也可以两面一起用——
让它告诉你存款够撑多久，也告诉别人你值多少钱。
目标用户：
简册的用户分三层。最里层是正在经历职业变动、同时又得盘算钱的人：裸辞或被裁后边海投边算存款的、收入忽高忽低的自由职业者、工作一两年一边月光一边看机会的职场新人——他们两件事都用。往外一圈是被其中一件事拉进来的：应届生和手握 offer 比价的人，简历是刚需，顺带开始记账；负债还款党、斜杠青年、转行者、要盘十几年家底的转型老手、每年年底复盘的人，两件事轮着来，谁先谁后不定。最外层是只用一个功能的：只记账的——学生、月光族、记账爱好者、小生意个体户、攒钱打卡的人、管一家账的人；只做简历的——被猎头找上门的、考公考研失利转求职的、只想申请实习的。
解决什么问题：简册要解决的是「打工人看不清自己底牌」——不知道自己还能撑多久，也不知道自己值多少钱，所以换工作、花钱，全凭感觉赌。

## 六个视图（主界面 + 5 个功能页，2026-09-30 新增主界面）

## AI 能力（2026-09-29 新增 · 2026-10-11 改版）

> **改版说明（v1.16）：不再自己调模型，改成「跳转官网」。**
> 原来简册自己接通云端大模型（前端要放 `endpoint` + `publishableKey`）；现在简册只做两件事 ——
> **把问题复制到剪贴板** + **新标签打开官网**。你用自己的账号去问，简册**不接触、不保存你的任何密钥**。

- **AI 简历助手**：把「记一条」攒下的经历拼成提示词 → 复制 → 新标签打开你选的那家官网 → 你按 `Ctrl+V` 粘贴提问，让它把经历改写成更专业的表述。
- **岗位匹配**：把岗位 JD + 你的经历拼成提示词 → 同上。六维打分标准（技术栈 30 / 经验 25 / 行业 15 / 学历 10 / 薪资 10 / 证书 10）写在提示词里，**让模型照这个标准评**。
- 打分口径来自 `projects/job-matcher/`（技能包），**口径完全一致**。
- **可选模型共 8 家，全是国内主流官网**：DeepSeek / Kimi / 千问 / 豆包 / 智谱清言 / 文心一言 / 腾讯元宝 / 讯飞星火。
- **零密钥**：简册里**没有**任何密钥输入框，也**不向任何模型接口发请求** —— 没有密钥可泄露。
- **问题文本绝不进网址**：只走剪贴板。进了网址就会落进浏览器历史、`Referer` 和对方服务器日志。
- **🔴 不爬取个人信息**：只处理你自己粘贴 / 自己填写的文字，**不访问任何招聘网站**。`contact`（手机号 / 邮箱）**绝不**拼进提示词。

## 数据与隐私

- **账目与个人参数**：存在云端数据库（CloudBase · PostgreSQL）里，**不需要注册账号**；同时在本机浏览器留一份副本，断网时也能看（v1.15 / Day 20 起）。
- **经历与岗位匹配记录**：**目前仍只存在你自己电脑的浏览器里**（`localStorage`）—— 对应接口还没实现，换设备看不到。
- **AI 功能不发任何数据出去**（v1.16 起）：简册只把提示词**复制到你的剪贴板**，发不发、发给谁，由你自己在模型官网里决定。简册不接触你的任何密钥。
- 备份 `.json` 文件是明文的，用记事本就能看懂——别把它放在别人能看到的地方。
