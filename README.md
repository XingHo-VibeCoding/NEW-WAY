项目名：Ledger and Career-简册
简介：
一本职场人的双面账簿。
第一面记钱：收支、账单、存款，看清每个月钱去哪了。
第二面记经历：工作、项目、成长，随时导出一份简历。
你可以只用其中一面，也可以两面一起用——
让它告诉你存款够撑多久，也告诉别人你值多少钱。
目标用户：
简册的用户分三层。最里层是正在经历职业变动、同时又得盘算钱的人：裸辞或被裁后边海投边算存款的、收入忽高忽低的自由职业者、工作一两年一边月光一边看机会的职场新人——他们两件事都用。往外一圈是被其中一件事拉进来的：应届生和手握 offer 比价的人，简历是刚需，顺带开始记账；负债还款党、斜杠青年、转行者、要盘十几年家底的转型老手、每年年底复盘的人，两件事轮着来，谁先谁后不定。最外层是只用一个功能的：只记账的——学生、月光族、记账爱好者、小生意个体户、攒钱打卡的人、管一家账的人；只做简历的——被猎头找上门的、考公考研失利转求职的、只想申请实习的。
解决什么问题：简册要解决的是「打工人看不清自己底牌」——不知道自己还能撑多久，也不知道自己值多少钱，所以换工作、花钱，全凭感觉赌。

## 五个页面

启动方式：双击根目录 `index.html`，浏览器打开即用。

| 面 | 页面 | 门牌号 | 干什么 |
|---|---|---|---|
| 账簿面 | 底牌页 | `#/home` | 看「还能撑几个月」、本月收支，填个人参数，导出 / 导入备份 |
| 账簿面 | 记一笔 | `#/expense` | 记收入 / 支出，按月看流水与合计 |
| 简历面 | 记一条 | `#/entry` | 记下做成了什么，攒成简历原料 |
| 简历面 | 简历预览 | `#/resume` | 经历排成一份可打印的简历；**AI 简历助手**逐条优化 |
| 简历面 | 岗位匹配 | `#/match` | 粘贴岗位 JD，AI 按六维打分并写开场白 |

## AI 能力（2026-09-29 新增）

- **AI 简历助手**：把「记一条」攒下的经历交给云端大模型，改写成更专业的简历表述。可自选模型。
- **岗位匹配**：粘贴岗位 JD，按六维标准（技术栈 30 / 经验 25 / 行业 15 / 学历 10 / 薪资 10 / 证书 10）算出匹配度 + 优势点 + 待提升 + 推荐开场白，自动存记录。
- 打分口径来自 `projects/job-matcher/`（技能包），**口径完全一致**。
- **免密钥**：云端应用自带套餐，不需要申请任何 API Key。
- **🔴 不爬取个人信息**：AI 只处理你自己粘贴 / 自己填写的文字，**不访问任何招聘网站**。联系方式绝不发给模型。

## 数据与隐私

- 所有账目、经历、岗位匹配记录**只存在你自己电脑的浏览器里**（localStorage），不上传、不注册。
- AI 功能会把**你主动提供的文本**（经历内容 / 粘贴的 JD）发给云端大模型；**联系方式不参与**。
- 备份 `.json` 文件是明文的，用记事本就能看懂——别把它放在别人能看到的地方。
